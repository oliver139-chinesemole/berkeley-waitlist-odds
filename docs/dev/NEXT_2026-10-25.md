## 6. Decisions made on Oliver's behalf (reversible; what each costs if wrong)

1. **Selection rule.** Section pages never expose `is_primary` (`classes_site.py` sets it None), so the plan's first option did not exist. The plain "class number below 100" rule was measured and dropped 177 real Fall primaries in 22 courses, so the rule is the union above. Cost: about 40 extra pages a run; a course whose lowest-numbered component is a secondary gets its secondaries fetched. To reverse: edit `primary_like` in `scraper/sources/classes_site.py` and section 19.
2. **Unknown-id 404s are answers, not missing pages.** Cost: a partial 404 episode is invisible to the missing share (follow-up above).
3. **The full-scope universe follows the same rule.** Cost: a complete full-scope run tombstones carried secondaries; full scope is not scheduled.
4. **Site copy** is conditional on the status where the status is in hand and date-free elsewhere; the fallback reads "begins with Phase 1 on Oct 26, 2026", true before and after that day.
5. **Pre-registration fields are carried onto an own-data export only from a meta of the same term and source**, not blindly as the plan said: otherwise the Accuracy page would print "The Spring 2027 cohort was frozen at 7f348ed", which is false. The gate keeps the published Spring 2026 meta anyway. Cost: a deliberate publish loses the pre-registration box until the copy follow-up lands.
6. **The weekly swap needs an explicit dispatch input**, never the count alone; the count and term checks stay as a sanity condition.
7. **Titles were built with `analysis.export --titles-only`**, not `make site-data`: the cohort files exist only in the main checkout and a full export would rewrite every site file.
8. **The docs do not repeat the plan's "every run for a month has written zero rows"**; the measured wording is above. The plan files themselves are committed verbatim.
